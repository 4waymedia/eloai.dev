00 · The thesis

Intelligence is not one thing.

It is the coordination of many faculties — each necessary, none sufficient alone. Intention without memory loops. Memory without reflection stagnates. Perception without emotion is blind to what matters.

EloAI is building each faculty as a discrete, testable system. They share a substrate. They pass structured data between them. They are not prompt engineering. They are math. — Position statement · EloAI Research

Two of the eight are shipped and validated today: Perception, the ELO vocabulary substrate, and Memory, the Mneme store. The rest are built in sequence on top of them. Everything below is what is actually true — measured, not claimed.

02 · Irin (the orchestrator)

The runtime that walks a Seed through the pipeline.

The eight systems share no state. Each is a standalone class with a single process(seed, context) method. Irin is the only component that knows the sequence — the conductor that takes a Seed and runs it through every faculty in order, propagating the result.

Before Irin runs, the Logic Matrix decides whether a Seed enters the pipeline at all. It scores each incoming Seed across twelve weighted activation dimensions — relevance to current goals, semantic distance from recent Seeds, recency, emotional significance, structural novelty, and others. Seeds below threshold are rejected before any system ever sees them.

Biological attention systems don't amplify everything — they suppress most of it. The interesting question isn't "what did the system notice?" but "what did it choose not to notice, and why?" — Field note · Logic Matrix, 2026.06.17
Pipeline stage

Irin v0.1.0 wires all eight systems end-to-end with five passing tests. Memory is in-process only for now; persistence and live-LLM integration are deferred to v0.2.

03 · The substrate (ELO)

Everything runs on ELO.

A canonical vocabulary of 374,189 entries where every English word and phrase maps to an integer ID. Not tokens. IDs. Byte-exact. Deterministic. Portable to C.

The substrate is the contract. Every system above it speaks ELO.

04 · Mneme (memory)

System 3 is Memory. We call it Mneme.

Named after the Greek goddess of memory. Mneme stores atomic units of meaning called MemorySeeds. Each seed carries:

Field
What it holds
entity_id · concept_id
What the seed is about.
vec4d
A 4D vector for cosine retrieval.
charge
EPA energy — Evaluation · Potency · Activity.
timestamp
Temporal ordering — memory as a time-ordered wave.
source
transcript · book · news · live event · human exchange.

Storage is temporal-first. An entity's memory is a time-ordered wave. Retrieval is pure 4D cosine similarity — no ML, no embedding API, no round-trip. Activation resolves in under 2ms on CPU across 10,000 seeds.

Contradiction candidates are flagged inline during storage and queued for System 8 (Reflection) to score.

05 · Validated results

What's measured, not claimed.

System 2 — Perceptionsemantic_compression v0.3.1

Compression
  • 20.1% fewer LLM tokens vs Qwen BBPE
  • 46.7% wire-format reduction vs Qwen fixed-width
  • 64.2% file-size reduction vs raw UTF-8

Vocabulary & training
  • 374,189 entries (206k words + 168k phrase atoms)
  • Qwen2.5-3B retrained on ELO — pilot perplexity ~81
  • 97.8% NN-transfer warm-start coverage

System 3 — MemoryMneme Phase 3

  • LMDB temporal-wave storage across 6 sub-databases
  • 4D cosine similarity retrieval — no ML, no embedding API
  • Activation resolves in <2ms on CPU across 10,000 seeds
  • Source-agnostic: transcript, news, url, book, audio, live_event, human_exchange
  • Contradiction detection inline during store — flagged for Reflection (System 8)
The 26 most-common English words (the, and, of, …) were defined as primitives in the config but never exported into the LLM tokenizer. The pilot briefly trained on a vocabulary missing its own most-frequent words. Found during validation. A 30-line fix produced ~50% improvement in key compression metrics. Engineering hygiene matters. — Field note · validation pass
