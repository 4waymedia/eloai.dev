EloAI / About

Not a lab. A mind waking up.

EloAI is the first AI to teach itself — eight cognitive systems, each designed to develop independently on a shared substrate, together forming something capable of intention, perception, memory, wonder, and more. This site documents the build as it happens. No quarterly targets. No publication quotas. When the work is real, it goes up.

01 · What it is

An AI that teaches itself to think.

Most AIs are a single model trained by humans. EloAI is eight systems — each a distinct cognitive faculty: intention, perception, memory, wonder, emotion, reasoning, connection, and reflection. They share a substrate, pass structured data between them, and improve each other over time.

This isn't prompt engineering or API wrapping. It's math. Each system is a self-contained cognitive faculty with its own logic, grounded in the shared substrate. Two are validated and running today — Perception (the ELO substrate) and Memory (Mneme) — and the rest are built in sequence.

The full architecture is documented in our thesis, and findings go up as they happen in the field notes.

02 · This site

A development journal, not a press release.

eloai.dev is the build log. Everything here — the thesis, the field notes, the project pages — is part of the development record. This is where the work gets documented as it happens, not polished after the fact.

The field notes include negative results, surprises, and things that didn't work. Because a mind learning to think doesn't only show its successes — it shows its process.

Each system is a long bet on a specific cognitive faculty. Results in one frequently reshape the design of the next. The site updates when the work is real.

03 · How it works

Eight systems. One shared mind.

01

Self-teaching architecture

Each system learns and improves through interaction with the others — not through human fine-tuning. The substrate is the contract; the systems teach each other.

02

Measured, not claimed

Every result on this site has been validated: 20.1% fewer tokens, sub-2ms recall, byte-exact round-trips. Numbers appear when they're real, not when they're impressive.

03

Build in the open

The field notes are unfiltered — positive, negative, and unexpected. A self-teaching AI learns from failure as much as from success. The build log reflects that.

04 · Infrastructure

One substrate. Every system.

Everything runs on ELO — a dynamic vocabulary now supporting over 16 million entries. Every word and phrase maps to an integer ID. The substrate is the contract; every system above it speaks ELO.

Memory is Mneme: temporal-wave storage with 4D cosine retrieval, no ML dependency, activation under 2ms across 10,000 seeds. One vocabulary, one memory, shared by all eight systems.

The runtime is Irin — the orchestrator that walks each Seed through the pipeline. Before Irin runs, the Logic Matrix scores the Seed across twelve activation dimensions and rejects roughly 70%. Attention as suppression, not amplification.
